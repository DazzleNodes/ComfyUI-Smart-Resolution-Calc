## Round 2

M6, M7 and M9 killed; M1 and M12 survived as triaged; M4 survived because the killing test's stray script exited 0 and pre-commit shows the tool's output only on failure. The test was corrected (the stray script now fails) and M4 re-run alone: killed (`v0.3.1__stubs-and-lib.round2b.report.json`). Sources restored and byte-verified after every mutant, and compared against an independent snapshot after each run.

**Cost note:** round 1 ran all three hook test files per mutant, about 2 minutes each; only the installer and pre-commit files could reach most of these mutants. Recorded for the testing-proportion review that follows this unit.

**Caveat:** a kill proves the suite noticed *this* change, not that it tests the right thing. A clean sweep is evidence about the mutations tried, not proof of suite completeness.
